Free Colour Reaction Game — Colour Rush

Colour Rush tests visual recognition and quick decision-making. A target colour appears above a set of tiles; your job is to identify the matching tile before the timer expires. Wrong taps cost lives, so speed needs to be balanced with accuracy.

Play Colour Rush →

How to play

  1. Start the challenge to begin the countdown.
  2. Read the requested colour carefully.
  3. Tap the matching tile as quickly as possible.
  4. Avoid incorrect tiles because mistakes cost a life.
  5. Keep playing until the timer ends or you run out of lives.

Why play Colour Rush?

  • The rules are simple enough for a quick break but demanding enough to reward concentration.
  • Each round changes the tile arrangement, so you cannot rely on one fixed position.
  • It combines visual search, choice reaction and accuracy in a short browser game.

Tips for a better score

  • Read the target before moving your finger or mouse.
  • Do not tap the first tile you notice — confirm its colour.
  • Reduce distractions if you are trying to improve your personal best.
  • Use a comfortable screen size so the colour tiles are easy to distinguish.

Frequently asked questions

Is Colour Rush a colour test?

It is a casual colour reaction game, not a clinical colour-vision test.

How do I score higher?

Prioritise correct answers while responding quickly. An incorrect tap can cost a life and end a run sooner.

Does Colour Rush work on mobile?

Yes. It is playable in modern mobile and desktop browsers.
